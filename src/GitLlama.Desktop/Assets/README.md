# GitLlama artwork

`gitllama.svg` is the user-supplied `alpaca-svgrepo-com.svg`; its original artwork and metadata are preserved. The in-app logo renders its vector paths directly.

`gitllama.png` and the multi-resolution `gitllama.ico` are rendered from that SVG by `scripts/generate-icons.cjs`, using Sharp. The icon includes 16, 24, 32, 48, 64, 128 and 256 pixel variants.
